# 2026 国庆旅行管家

一个为 2026 国庆威海 → 青岛 → 南京旅行制作的静态网站。

## 功能
- 实际火车/住宿日期版行程时间线
- 中山陵、明孝陵、音乐台、鸡鸣寺、牛首山预约清单
- 今日预约提示
- 本地保存“已预约/购票”状态
- Web Share 分享
- 一键下载 `.ics` 景点预约提醒日历
- PWA manifest
- GitHub Pages 自动部署 workflow

## 部署
仓库推送到 `main` 后，GitHub Actions 会尝试部署 GitHub Pages。
首次使用通常需要在仓库 `Settings → Pages` 中将 Source 设为 **GitHub Actions**。

## 关于提醒
静态 GitHub Pages 无法保证网页关闭后在 iPhone/浏览器中每天后台主动推送，因此网站只负责实时状态和日历提醒。
ChatGPT 里已经建立的每日预约检查任务继续负责主动提醒。

## 票务规则
网页不会把未经官方公开确认的“提前 N 天、几点放票”写死。重点：
- 中山陵：实名预约免费参观，目标日期开放后立即预约。
- 明孝陵/音乐台：收费景点，可线上或现场购票，国庆前建议提前处理。
- 牛首山：预约分时入园，10 月 1 日目标日期开放后立即购买。
- 鸡鸣寺：临近日期再次核对官方节假日公告。
